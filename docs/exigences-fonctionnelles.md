# Exigences fonctionnelles — EduProgress

## 1. Gestion des utilisateurs

**EF-01** — L’utilisateur doit pouvoir se connecter à l’application avec un compte personnel.

**EF-02** — L’accès aux fonctionnalités doit dépendre du rôle : professeur, élève, parent ou administrateur.

**EF-03** — Le professeur doit pouvoir créer et gérer le profil d’un élève.

**EF-04** — Un élève peut être associé à un ou plusieurs comptes parents.

**EF-05** — Un parent ne peut consulter que les informations des élèves auxquels il est associé.

**EF-06** — L’utilisateur doit pouvoir consulter et modifier les informations de son profil.
